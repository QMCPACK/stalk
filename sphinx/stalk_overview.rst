STALK package overview
=======================

This page gives a short introduction to the ``stalk`` Python package and how its
subpackages are organised.

Quick summary
-------------

- **Project:** Surrogate Theory Accelerated Line-search Kit (STALK).
- **Purpose:** Tools for performing parallel line-search optimization, surrogate
  modeling, and related utility code for parameter and geometry handling.

Installing and importing
------------------------

The package exposes a compact top-level API. Example usage:

.. code-block:: python

   import stalk

   # create a line-search settings object
   settings = stalk.LsSettings()

   # use a fitting helper
   fit = stalk.MorseFit()
